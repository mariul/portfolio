# Maria Cristina Gheorghiu — Architecture Portfolio

A flip-through version of my A3 architecture portfolio (TU/e, Architecture, Urbanism and Building Sciences).

**Live site:** https://mariul.github.io/portfolio/

## What's inside

| Path | Contents |
|---|---|
| `index.html` | The flipbook (booklet and one-page views, zoom, contents folder) |
| `pages/` | Page images used in the book (27 pages) |
| `hi/` | High-resolution pages for the zoom view |
| `Maria_Cristina_Gheorghiu_Portfolio.pdf` | Downloadable PDF of the portfolio |
| `*.png`, `bg.jpg` | Hand cut-outs, view icons and background |

No build step: it is a plain static site.

## Publishing on GitHub Pages

1. Create a new **public** repository on GitHub (for example `portfolio`).
2. Upload everything in this folder (drag the files into "Add file → Upload files", or push with GitHub Desktop).
3. In the repository go to **Settings → Pages**, set **Source: Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. After a minute the site is live at `https://YOUR-USERNAME.github.io/portfolio/`.

Tip: name the repository `YOUR-USERNAME.github.io` to get the shorter address `https://YOUR-USERNAME.github.io/`.
